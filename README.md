DFA Simulator — Python OOP Implementation
A Python implementation of a Deterministic Finite Automaton (DFA) from scratch using object-oriented design. The simulator accepts a formal DFA definition from the user — states, alphabet, start state, final states, and transitions — validates it against all DFA formation rules, constructs the machine, and runs it on input strings with a full step-by-step trace showing each state transition and a final accept/reject verdict.
Currently in development. Planned features include NFA support, regex to DFA conversion, and a visual diagram of the automaton.
